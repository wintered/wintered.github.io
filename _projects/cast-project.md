description: |
    Commit-Aware Solver Testing (CAST) continuously tests SMT solvers: every new commit is automatically built and fuzzed against a reference solver, so bugs are caught as soon as they're introduced rather than long after the fact. The goal of CAST is to make continuous, automated bug-hunting a routine part of maintaining an SMT solver, turning testing from an occasional effort into an always-on safety net.
